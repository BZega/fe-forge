About the Developer

Built by a fan, for fans

Hi! I'm a software developer and lifelong Fire Emblem fan. Fire Emblem Forge started as a handful of excel spreadsheets I used in order to plan my own playthroughs. This eventually grew into the set of tools you see here. I will continue to work hard to improve and expand Fire Emblem Forge for the community.

It's a passion project built in my free time, and it will always be free to use. If you have an idea or spot something wrong, the Suggestions button in the menu comes straight to me.

If FE Forge has helped you plan the perfect run and you'd like to support its continued development, tips are always appreciated, but never expected.

FE Forge is a fan-made project and is not affiliated with Nintendo or Intelligent Systems.
